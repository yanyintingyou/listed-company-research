# 金山软件 / 金山办公：控股集团 + A股子公司联合研究案例

## 适用场景
当研究一个港股/海外控股集团，同时其核心资产是A股上市子公司时，可复用本案例的核验与估值框架。

## 文件与数据源模式
- 港股公司：优先使用 HKEX 公告原文或公司 IR 年报英文版。
- A股子公司：优先使用交易所/巨潮/东方财富 PDF；若搜索不到最新文件，可用新浪公告 HTML 中隐藏的 PDF 链接作为兜底。
- 下载后必须验证：文件类型、页数、公司名称、股票代码、报告期。
- 用 PyMuPDF 提取文本后，直接定位利润表、现金流量表、分部信息、股东权益、业务指标章节。

## 关键分析陷阱
1. **金山软件与金山办公不能简单合并看估值。**
   - 金山软件是控股集团，包含游戏业务和对金山办公的持股。
   - 金山办公是A股高估值办公软件/订阅/SaaS资产。
   - 对金山软件更适合使用 SOTP，而不是只看合并 PE。
2. **金山办公季度利润需剔除非经常性投资收益。**
   - 若某季度归母净利润因基金/股权投资公允价值变动大幅异常，应使用扣非或调整后 TTM，不可直接年化。
3. **控股公司折价必须显性列示。**
   - 计算金山软件持有金山办公股份市值。
   - 再假设 30%/50%/70% 折价，观察市场对游戏业务及其他资产的隐含定价。
4. **口径必须清楚区分。**
   - 港股价格/市值常用 HKD；A股子公司用 CNY。
   - SOTP 时需统一汇率口径。

## 估值模板
- 子公司持股价值：
  `持股股数 × 子公司当前股价`
- 控股集团市值人民币口径：
  `港股价格 × 股本 / CNYHKD`
- 折价后持股价值：
  `子公司持股价值 × (1 - 控股公司折价)`
- 隐含其他资产价值：
  `控股集团市值 - 折价后子公司持股价值 + 净债务调整`

## 输出建议
- 将事实拆成两类：
  - 【原文披露】：年报/季报直接披露数字和业务表述。
  - 【分析判断】：估值假设、折价解释、投资结论。
- 对投资建议要同时写“为什么便宜”和“为什么可能长期便宜”。控股公司折价不自动等于套利机会，需讨论催化剂。
