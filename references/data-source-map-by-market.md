# 分市场数据源路由

## 总原则

一手披露优先，行情和数据库仅作辅助。所有数据必须标注来源、日期、货币、口径和是否为原始披露。

如果官方文件无法直接提取，必须说明：

1. 阻塞原因；
2. 使用的替代来源；
3. 替代来源层级；
4. 哪些结论因此置信度下降。

## 美股

### 一手来源

1. SEC EDGAR filing HTML：10-K、10-Q、8-K、S-1、20-F、6-K。
2. SEC companyfacts XBRL：适合批量抓收入、利润、现金流、股本、债务等标准化概念。
3. 公司 IR：earnings release、shareholder letter、presentation、transcript。

### 行情与估值补充

- Stooq CSV：价格兜底。
- Nasdaq / NYSE / company IR quote page。
- TradingView / Yahoo / StockAnalysis：只用于行情、市值、基础倍数交叉验证。

### 注意事项

- filing HTML 通常比 PDF 更完整。
- 直接引用风险披露和管理层措辞时，应抓 filing 原文前后文。
- TTM 指标若由 FY + 当前季度 - 去年同期季度计算，必须标注为“基于原始披露的计算”。
- Non-GAAP 指标必须回到公司 reconciliation 表。

## 港股

### 一手来源

1. HKEXnews 公告原文。
2. 公司 IR 英文版年报/中报/公告；多数港股英文版为法定版本。
3. 业绩发布 PPT、公告、电话会纪要。
4. 若为 H 股/A+H，需同步检查 A 股公告。

### 补充来源

- 东方财富港股 F10。
- 富途牛牛。
- 新浪财经。
- TradingView / Yahoo 仅作行情兜底。

### 注意事项

- 财报货币常为 CNY/USD，交易货币常为 HKD。
- SOTP 估值必须统一货币后再换算每股价值。
- 控股集团必须区分母公司层、合并层、子公司层、联营公司层。
- 中文版通常可读性更好，但出现歧义时以英文版为准。

## A 股

### 一手来源

1. 巨潮资讯。
2. 上交所、深交所、北交所公告。
3. 公司 IR、投资者关系活动记录。
4. 年报/季报 PDF 直链：巨潮、交易所、东方财富公告 PDF、新浪公告 PDF。

### 补充来源

- 东方财富 F10。
- 同花顺/雪球/新浪财经。
- 交易所互动平台。
- Wind/iFinD/Choice：如用户有权限，可用但必须标注数据库口径。

### 注意事项

- 财报单位常为元、万元、亿元，摘录时必须统一。
- A 股季报信息量较少，需结合年报和投资者关系活动记录。
- 业绩预告、业绩快报、问询函、监管函是重要信号。
- 每股数据需确认是基本 EPS、稀释 EPS、每股净资产还是每股经营现金流。

## 跨市场比较

跨市场比较必须处理：

- 交易货币差异。
- 财报准则差异：PRC GAAP、IFRS、US GAAP。
- 财年结束日差异。
- ADR 比例。
- 总股本与 ADS/ADR 股本换算。
- 税率、监管和流动性折价。

## 行情数据硬规则

股价、汇率、市值、PE/PB/PS/EV/EBITDA、股息率均为时间敏感数据。除非用户明确要求复盘历史时点，否则必须重新获取并标注：

- 数据日期。
- 数据来源。
- 使用货币。
- 收盘价/盘中价/复权价。
- 计算公式和股本口径。
