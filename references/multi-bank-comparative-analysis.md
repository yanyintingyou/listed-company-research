# 银行股多标的横向对比分析框架

## 适用场景
同时分析多家银行（或其他同行业公司）的投资价值，进行横向对比排序。

## 加权评分模型

### 维度与权重（银行股适用）

| 维度 | 权重 | 核心指标 | 评分逻辑 |
|------|------|----------|----------|
| **估值** | 30% | PE、PB、股息率 | PE越低越好(40%)、PB越低越好(40%)、股息率越高越好(20%) |
| **盈利能力** | 25% | ROE、ROA、净息差 | ROE(50%)、ROA(30%)、NIM(20%)，均越高越好 |
| **资产质量** | 25% | 不良贷款率、拨备覆盖率 | 不良率越低越好(50%)、拨备覆盖率越高越好(50%) |
| **资本充足率** | 10% | 核心一级资本充足率 | 越高越好 |
| **增长** | 10% | 总资产增速、ROE趋势 | 总资产环比增速(50%)、最新季度ROE(50%) |

### 评分计算方法

```python
def calculate_score(values, higher_is_better=True):
    """相对评分法：最高分10分，其他按比例"""
    if higher_is_better:
        max_val = max(values)
        return [10 * (v / max_val) for v in values]
    else:
        min_val = min(values)
        return [10 * (min_val / v) for v in values]
```

### 各维度得分计算公式

```
估值得分 = PE得分×0.4 + PB得分×0.4 + 股息率得分×0.2
盈利得分 = ROE得分×0.5 + ROA得分×0.3 + NIM得分×0.2
资产质量得分 = 不良率得分×0.5 + 拨备覆盖率得分×0.5
增长得分 = 总资产增速得分×0.5 + ROE季度得分×0.5

综合得分 = 估值得分×0.30 + 盈利得分×0.25 + 资产质量得分×0.25 
         + 资本充足率得分×0.10 + 增长得分×0.10
```

## 银行股核心指标体系

### 估值指标
- **PE（市盈率）**：股价 / 每股收益（TTM或最新年报）
- **PB（市净率）**：股价 / 每股净资产
- **股息率**：每股分红 / 股价 × 100%

### 盈利能力指标
- **ROE（净资产收益率）**：净利润 / 股东权益
- **ROA（总资产收益率）**：净利润 / 总资产
- **净息差（NIM）**：利息净收入 / 生息资产平均余额

### 资产质量指标
- **不良贷款率**：不良贷款余额 / 贷款总额
- **拨备覆盖率**：贷款减值准备 / 不良贷款余额
- **关注类贷款占比**（补充指标）
- **逾期贷款率**（补充指标）

### 资本充足指标
- **核心一级资本充足率**（CET1）
- **一级资本充足率**（Tier 1）
- **资本充足率**（CAR）
- **杠杆率**

### 规模与增长指标
- **总资产规模**
- **贷款总额增速**
- **存款总额增速**
- **净利润增速**

## 投资者类型适配

| 投资者类型 | 核心关注 | 指标权重调整 |
|------------|----------|--------------|
| **价值投资者** | 低估值、安全边际 | 估值权重提高至40%+ |
| **成长投资者** | 盈利能力、增长潜力 | 盈利+增长权重提高至50%+ |
| **收入投资者** | 高股息、稳定分红 | 股息率权重提高至30%+ |
| **防御投资者** | 资产质量、资本充足 | 资产质量权重提高至35%+ |

## 银行股特殊考量

### 国有大行 vs 股份行的可比性
- 国有大行（工农中建交）：规模大、ROE偏低、股息率高、估值低
- 股份行（招商、兴业、平安等）：ROE高、成长性好、估值较高
- 直接对比时需注意"类型溢价"：股份行的高ROE可以支撑更高PB

### 净息差的结构性因素
- 资产端：贷款结构（零售vs对公）、利率环境
- 负债端：存款成本（活期占比）、同业负债成本
- 对比时应关注趋势变化而非绝对水平

### 资产质量的前瞻性指标
- 关注类贷款迁徙率
- 逾期90天以上贷款与不良贷款的比值
- 拨备计提充足程度（拨备/贷款总额）
