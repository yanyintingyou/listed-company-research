# 保险公司专项分析框架

## 适用场景

当研究对象是寿险、财险、再保险、综合保险集团，或金融控股集团中保险业务占重要价值时，使用本 reference。

保险公司不能简单套用普通企业 PE/DCF。保险业务的核心是长期负债、投资资产、资本约束和利率敏感性，因此必须穿透看营运利润、内含价值、新业务价值和偿付能力。

## 核心指标

### 寿险

- **营运利润**：剔除短期投资波动和一次性项目后的利润，是估值核心。
- **内含价值 EV**：调整净资产 + 有效业务价值。
- **新业务价值 NBV**：当年新售保单未来利润现值，是寿险造血能力指标。
- **新业务价值率 NBV margin**：NBV / 首年保费或等价口径。
- **EV 营运回报率**：营运利润 / 期初 EV。
- **代理人数量与产能**：数量下降不一定坏，需看人均产能和产品结构。

### 财险

- **综合成本率**：赔付率 + 费用率，低于 100% 表示承保盈利。
- **车险综合成本率**：判断车险主业质量。
- **非车险结构**：保证保险、责任险、健康险等风险差异大。
- **准备金充足性**：关注历史赔付发展和准备金释放。

### 偿付能力

- 综合偿付能力充足率。
- 核心偿付能力充足率。
- 偿二代/监管规则变化。
- 利率下行对资本和负债现值的影响。

## 估值方法

### P/EV

保险公司最核心估值方法之一：

```text
P/EV = 市值 / 内含价值
```

判断时必须结合：

- NBV 增速。
- EV 增长质量。
- 投资回报假设是否审慎。
- 利率环境。
- 公司治理与资本配置。

### P/Operating EPS

用营运利润计算 PE，而不是报告净利润：

```text
P/Operating EPS = 股价 / 每股营运利润
```

报告净利润可能被权益市场、公允价值变动、减值和一次性项目扭曲。

### NBV 倍数法

适合评估寿险新业务增长价值。高 NBV 增速和高 NBV margin 可以支持更高倍数。

### DDM

适合分红稳定、资本充足的大型保险公司。分红基础应优先使用营运利润和可分配利润，而不是短期报告净利润。

## 关键风险

1. **利率风险**：长期利率是保险估值的锚。利率下行会压缩投资收益并抬升负债压力。
2. **投资收益波动**：权益资产和长期债券公允价值变化会放大净利润波动。
3. **假设变更**：投资回报率、风险贴现率、死亡率/退保率等假设变化会影响 EV/NBV 可比性。
4. **偿付能力约束**：资本不足会限制新业务扩张和分红。
5. **产品结构变化**：短储、保障、分红、万能险产品价值率差异很大。
6. **渠道质量**：代理人、银保、互联网渠道的价值率和持续率不同。

## 数据源

- 公司年报、中报、偿付能力报告。
- 公司业绩公告和 investor presentation。
- 港交所/上交所/深交所公告。
- 监管披露和偿付能力报告摘要。
- 财经媒体摘要仅作补充，不可替代官方披露。

## 输出要求

保险公司研究至少输出：

- 报告净利润 vs 营运利润差异。
- EV、NBV、NBV margin、EV operating return。
- 投资收益率和资产配置。
- 偿付能力。
- P/EV、P/Operating EPS、股息率。
- 利率敏感性和假设变更影响。
- 结论：估值便宜是因为周期错杀、利率压制、业务恶化，还是资本市场误读。
