# 文章来源逐条核验模板

## 使用场景

当用户要求“给每个来源附上链接/原文表述”“逐条核验文章事实”“审计报告来源”“区分原文和推断”时，使用本模板。

## 核验原则

每条事实都必须归入以下之一：

- **A 类：文件直接披露** — 年报、季报、招股书、公告、SEC filing、公司 IR 原文直接给出的数据或表述。
- **B 类：基于文件数据的计算** — TTM、同比、FCF、估值倍数、安全边际等由原始数据计算得到。
- **C 类：分析性判断/推断** — 商业模式、护城河、风险概率、估值假设、投资结论。
- **D 类：二手来源信息** — 新闻、研报、数据库、行情平台、社交媒体。

A/B 类可以作为硬证据；C 类必须标注推断逻辑；D 类必须说明是否已回溯到原始来源。

## 逐条核验模板

```md
## [章节/主题]

### Claim 1

- 原文/文章表述：
- 核验类型：A/B/C/D
- 来源：
- 页码/章节/URL：
- 原文摘录：
- 核验结果：✅ 准确 / ⚠️ 不够精确 / ❌ 错误 / 🔍 推断
- 修正值或更准确表述：
- 备注：
```


## 常见易错点

- 把媒体转述当作公司原文。
- 引用公司中文翻译但忽略英文法定版本。
- TTM、同比、FCF 等计算没有标注公式。
- 股价、汇率、市值没有基准日。
- 把“分析性判断”写成“文件披露事实”。
- 只核验最终 Markdown，不检查原始 Excel、脚本、模型和中间 CSV。
