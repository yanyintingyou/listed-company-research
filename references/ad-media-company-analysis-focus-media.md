# 广告/媒体公司分析框架 — 以分众传媒(002027.SZ)为案例

## 适用范围
- 梯媒/户外广告公司（分众传媒、兆讯传媒、新潮传媒）
- 生活圈媒体、场景营销公司
- 传统媒体+数字广告混合型公司

## 商业模式特征识别

### 广告媒体公司的财报原文信号
1. **收入确认方式**："广告完成播放且满足条件时确认"（分众2024年报P.8）→ 按服务完成确认，非订阅制
2. **成本结构**：媒体资源成本占营业成本73.35%（分众2024年）→ 核心成本是物业租赁，非人力
3. **毛利率区间**：成熟期65-70%（分众），成长期55-60% → 高毛利率反映定价权+规模效应
4. **生产资本回报率**：>500%（分众825.71%）→ 极轻资产模式

### 楼宇/户外媒体特殊指标
| 指标 | 含义 | 健康标准 |
|------|------|----------|
| 媒体设备数量 | 覆盖规模（电视/海报/屏幕） | 行业龙头通常>100万台 |
| 城市覆盖数 | 地域广度 | >300城市为全国性网络 |
| 设备利用率 | 实际出租/可用 | 公司通常不直接披露 |
| 日用消费品占比 | 客户结构稳定性 | >50%为抗周期（刚需消费品） |
| 媒体资源成本增速 | 物业租金压力 | 应低于营收增速 |

## 关键风险模式

### 1. 宏观周期敏感性
- 广告是**可选支出**，经济下行时最先被砍
- 2022年案例：分众营收-36.5%（疫情冲击），净利-53.5%
- **缓解信号**：日用消费品占比提升（刚需属性）

### 2. 收入结构突变风险
- 2024→2025年分众案例：日用消费品-16%，互联网+188%
- 收入结构剧烈变化可能掩盖主营业务压力
- **分析要点**：分板块拆解增速，识别结构性变化vs一次性波动

### 3. 联营公司减值风险
- 户外媒体公司常投资广告技术/金融科技公司
- 分众案例：数禾科技减值25.29亿（Q4巨亏主因）
- **分析公式**：核心净利 = 报告净利 + 联营减值 + 资产处置损失

### 4. 行业整合风险
- 并购是户外媒体扩张的主要手段
- 分众收购新潮（83亿）：需关注估值合理性、整合风险、反垄断审批
- **估值陷阱**：标的PE 198倍（新潮），但战略价值>财务价值

## 估值方法选择

### 广告媒体公司适用方法
1. **相对估值**：PE、PB、EV/EBITDA（轻资产公司PB可能极低）
2. **DCF**：适合现金流稳定的成熟公司
3. **概率加权**：宏观周期敏感型公司必须做情景分析

### 广告媒体公司不适用方法
- P/S（广告公司收入波动大，P/S意义有限）
- SOTP（除非是综合企业集团）
