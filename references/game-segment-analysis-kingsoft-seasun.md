# 金山软件/西山居游戏业务分析补充案例

适用：在上市公司研究中分析游戏分部、老IP生命周期、新游商业化、代理发行与自研能力差异时参考。

## 一手数据与交叉验证路径

1. **公司原文披露优先**
   - 金山软件年报/业绩公告披露分部收入、管理层对游戏业务的解释、核心产品进展。
   - 2025年金山软件网络游戏及其他业务收入为人民币37.54亿元，同比下降28%；集团总收入96.83亿元，同比下降6%。
   - 年报解释：下滑主要反映上年同期高基数及现有游戏收益下降。
   - 年报披露《鹅鸭杀》2026年1月上线，首日新增用户超500万，累计新增用户超3000万，过去两个月大部分时间登顶iOS免费榜，仍处商业化早期。
   - 年报披露《愤怒的小鸟》系列两款休闲游戏已获版号，预计2026年国内上线；《星砂岛》2026年2月开启抢先体验，预计下半年正式版上线。

2. **第三方运营数据用于验证，而非替代财报**
   - 对PC/Steam产品，可用 Steambase/SteamDB 等验证同时在线、用户评价、留存衰减。
   - 案例：《解限机》上线初期Steam历史峰值约13.27万人；2026年5月平均在线约1151人、峰值约1639人，Steam评价为Mixed。这类数据可证明“初期热度高但长线留存弱”。
   - 使用时必须标注为第三方数据，不要等同于公司披露收入或流水。

3. **财务指标计算模板**
   - 游戏收入同比：`current_game_revenue / prior_game_revenue - 1`
   - 游戏收入占比：`game_revenue / total_revenue`
   - 游戏下滑对集团收入下滑解释度：`game_revenue_decline / total_revenue_decline`
   - 新游留存衰减粗略指标：`current_avg_concurrent / launch_month_avg_concurrent` 或 `current_peak / all_time_peak`

## 分析框架

### 1. 游戏公司/分部不要只看“有没有新品”，要拆成四层

- **基本盘现金牛**：老IP、老MMO、长线社区，例如《剑网3》《剑侠世界：起源》。重点看活跃用户稳定性、版本更新、付费深度、IP生命周期。
- **自研大项目期权**：例如《解限机》。重点看上线后留存、评价、内容迭代、商业化，而不是预约量、测试热度、媒体评分。
- **代理/发行型爆款**：例如《鹅鸭杀》。重点看DAU、留存、付费率、ARPPU、收入榜排名。代理爆款能改善收入，但不能直接证明自研体系恢复。
- **中小型品类试验**：例如休闲IP、田园生活模拟等。重点看口碑、长尾销量、买量效率、全球发行能力。

### 2. 老IP稳定 ≠ 增长

长线IP是现金流底盘，但投资分析不能把“稳定运营”自动外推为增长。需要核验：
- 用户结构是否老化；
- 新增用户来源是否充足；
- 内容更新是否越来越重；
- 是否存在一次性高基数；
- 同赛道竞品是否分流。

### 3. 新游验证优先级

对新游，优先看：
1. 上线后30/60/90日留存与活跃；
2. DAU/MAU是否稳定；
3. 收入榜排名和流水曲线；
4. 评价是否持续改善；
5. 营销费用是否换来可持续用户；
6. 是否需要不断大买量维持热度。

不要只看：预约人数、首日新增、免费榜排名、媒体评分、测试峰值。这些是初始热度，不是商业成功。

### 4. 组织调整信号的解释

若出现CEO/制作人职责调整、收缩非战略项目、强调AI增效等表述：
- 正面：说明公司开始纠偏，资源向核心项目集中；
- 负面：也说明过去项目机制、资源分配或大项目投入产出可能有问题；
- 不应把“AI提升效率”直接视作利润反转，AI更多改善美术、剧情、关卡、运营素材生产效率，无法替代玩法设计、社区运营和商业化判断。

## 输出建议

对游戏分部给投资结论时，用“三情景”：
- **乐观**：老IP稳住 + 新代理商业化 + 中小品类正式版成功 + 大项目修复；
- **中性**：老IP稳定，新品贡献有限，收入低位震荡；
- **悲观**：老IP下滑，新品热度衰退，费用刚性继续压利润。

在综合企业SOTP中，游戏分部宜拆成：
- 老IP现金流价值；
- 新品/全球化/AI生产效率期权；
- 对失败大项目给予折价或暂不赋予高估值。
