# Examples

Small synthetic examples for testing or demonstration can be added here.

Suggested example prompts:

1. **Single-company deep dive**
   - “Analyze a listed company's latest annual report using primary sources. Return a data-source audit table, financial-quality analysis, valuation-method choice, and top risks.”

2. **Multi-company comparison**
   - “Compare three banks using consistent P/B, ROE, NIM, asset-quality, capital-adequacy, and dividend-yield metrics.”

3. **Source-verification audit**
   - “Audit this investment memo. Classify each claim as direct disclosure, calculation, analytical judgment, or secondary-source information.”

4. **Model consistency audit**
   - “Check an equity valuation workbook for currency, share-count, FCF, DCF terminal-value, and SOTP consistency errors.”
